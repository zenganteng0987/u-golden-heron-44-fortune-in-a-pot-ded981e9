One kind, funny fortune for a houseplant, in a single line of at most 120 characters.

## Run

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` (override with `OUTPUT_PATH`).

## Entry

> This week, a sunbeam will find your favorite leaf, and you will spend the afternoon showing off for the window.
